02 — KERNMODULE

Audio Engine & DJ-Workstation

Die Kernfunktionalität: Native Waveforms, Mastering, Key/BPM Analyse, Curation und Traktor Export

AuraMaster — Mastering Engine

PRODUKTIV
  • FFT-Spektrum-Analyzer (44.1 kHz, High-Res Buffer)
  • Automatische LUFS-Normalisierung (-12 LUFS Target)
  • 3 Modi: Power Block, Sanft Harmonisch, Peak Focus
  • Hermetisches FFmpeg Sidecar (Echte Filterkette)
  • Output: key_bpm_songname_artist.wav

AuraHarmonics — Key/BPM & Camelot

PRODUKTIV
  • Hermetisches Python DSP Binary (librosa Engine)
  • Camelot Harmonic Wheel (1A–12B) Visualisierung
  • Harmonisches Set: Automatische Camelot-Sortierung
  • Übergangs-Scoring zwischen Tracks
  • Traktor-Theme-Farben für Wheel und Decks

Dual-Deck DJ Player

PRODUKTIV
  • Deck A/B mit Metal-GPU Waveform Canvas
  • Crossfader mit Echtzeit-Mixing Engine
  • BPM-Sync & Scratch/Pitch Controls
  • ORIG / MASTER Quellmodus-Umschaltung
  • Cue-Point Management (Add/Edit/Remove)

AuraCurator — KI-Playlist

KI / GEMINI
  • Gemini 1.5 Pro als Musikologe & Archivar
  • KI-Playlist-Sortierung nach Energie & Harmonie
  • Transition-Tipps & Harmonic Compatibility
  • Beat-Sync FX: FLTR, STTR, DLAY, RVRB
  • Dynamische Energie-Kurve (Intro/Main/Outro)

AuraMetal — GPU Waveform Engine

NEU V2.0
  • Apple Silicon Metal Compute Shader Pipeline
  • Direct Unified Memory Peak Pyramid Calculation
  • Null CPU Overhead bei Zoom & Waveform Scrolling
  • Automatischer Fallback auf Rust Multithread CPU
  • Integrations-Brücke zu React Canvas Component

AuraTraktor & Apple Music

PRODUKTIV
  • Import: Drag&Drop, Ordner-Scan, JSON, NML
  • Export: .nml, .m3u, .csv (Traktor Pro 4 Ready)
  • Apple Music Integration via JXA Bridge (osascript)
  • Pfad-Auflösung bevorzugt masteredPath
  • Real-time Directory Watching (FSEvents)
